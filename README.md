# צחצוח ערב

אפליקציה שמזיזה את צחצוח הערב מ"לפני השינה" ל"מיד אחרי הארוחה האחרונה". אחרי הארוחה שותים רק מים, אז אין אוכל שיקבל טעם של משחה ואין "כבר מאוחר מדי".

React Native + Expo (SDK 58), Expo Router, עברית ו-RTL מלא, מצב כהה. הכול נשמר מקומית במכשיר: בלי שרת, בלי התחברות ובלי אינטרנט.

## הרצה

```bash
npm install
npx expo run:android      # או: npx expo run:ios
```

האפליקציה משתמשת במודולים נייטיביים (התראות מקומיות, מצלמה, רטט, בורר תאריכים, RTL כפוי), ולכן מריצים אותה כ-development build ולא ב-Expo Go. בנייה בענן: `npx eas-cli@latest build --profile development`.

## בדיקות

```bash
npm test           # לוגיקה: יום לוגי, טיימר, רצף ומגן, תכנון התראות
npm run typecheck
npm run lint
```

## החלטות מימוש

- **התראות:** בכל פתיחה, בכל שינוי ובכל סימון צחצוח, מבטלים את כל ההתראות ומתזמנים מחדש ל-7 הימים הבאים. ככה ההתראות מגיעות גם אם האפליקציה לא נפתחת, וסימון ערב מבטל מיד את מה שנשאר לאותו ערב. מקסימום 3 התראות בערב ואף אחת אחרי שעת השינה.
- **צחצוח חלקי:** עצירה באמצע נשמרת כ-`partial`. אם הוא נמשך דקה לפחות, הוא נספר לרצף ומוצג בלוח כחצי נקודה. מתחת לדקה הוא נשמר אבל לא נספר. גרסת ההצלה תמיד נספרת.
- **מגן:** פספוס כשהמגן פעיל שובר אותו והרצף נשמר. פספוס כשהמגן שבור מאפס את הרצף. 7 ערבים רצופים מחזירים את המגן.
- **תזכורת בוקר:** כשמפעילים אותה בוחרים גם שעה (ברירת מחדל 08:00). לכן נוסף ל-`Settings` השדה `morningReminderTime`.
- **הלבנה:** התמונות מועתקות לתיקיית המסמכים של האפליקציה. הגרף מתקדם מימין לשמאל, וקו מקווקו מסמן את החלפת המשחה.
